# 主线玩法与章节任务

## 系统名称与用途

主线文档负责串联各玩法、读取任务目标、处理奖励和核验章节完成；具体单项操作由各玩法文档负责。已验证阶段为内网开发服第一章《冒险伊始》、第二章《雾隐迷塔》和第三章《装备锻造》。构建及特权未知。

## 入口与识别

主城左下任务清单图标可打开主线任务面板。点击任务文字区域可能领取奖励或触发指向相关系统的手势，不一定打开面板。面板按章节展示目标、奖励及完成状态；红徽标提示待处理内容，不能单凭徽标确认整章完成。

## 推进指定章节的路径

1. 从任务清单核对当前章节及目标；以用户指定终点限定范围。
2. 阅读当前任务，按手势或玩法独立入口前往操作页。建筑见[城镇建筑](buildings.md)，遭遇战见[战斗](combat.md)，招募见[英雄招募](recruitment.md)，培养见[英雄培养](heroes.md)，塔层见[雾隐迷塔](tower.md)，派遣/野外见[英雄营地与野外探索](field.md)，打造/穿戴见[装备系统](equipment.md)。
3. 在玩法完成画面核验目标，再回任务栏检查计数和可领取状态；领取逐项奖励后重新读取任务，因为后续目标可能此时出现。
4. 当前目标完成后领取章节奖励，再核对稳定的章节面板。“所有任务均已完成”可能只是切换中的短暂显示，不能据此认定没有后续章节。
5. 达到指定章的完成条件即停止；新章目标只用于确认章节切换，不自动执行。

## 各章串联路径

### 第一章：冒险伊始

地图魔物战 → 招募英雄 → 一名英雄升到10级 → 首领战 → 木材场、煤炭场、铁矿场、净化中枢建设引导 → 核对第一章面板及奖励。具体操作分别引用对应玩法；顺序为实际新手体验，不作为全版本固定任务表。

### 第二章：雾隐迷塔

建造地下城 → 探索迷塔并完成第3层 → 第5层 → 史诗招募10次、3名英雄Lv.10 → 4名英雄Lv.10、第10层 → 1名英雄达到1星 → 逐项及章节奖励。每次领取后查看新目标；显示计数和绿色勾冲突时按第二章任务和章节奖励需分别核验记录并核验，不将异常当作规则。

### 第三章：装备锻造

本次实际从建造英雄营地开始，经以下任务串联：

1. 建造英雄营地 → 解锁迷雾小径 → 派遣4名英雄 → 观看自动击杀3个怪物 → 拾取掉落物3次。操作见[field.md](field.md)。
2. 建造铁匠铺 → 打造普通练习剑 → 1名英雄穿戴武器 → 拾取掉落物5次 → 打造普通练习弓 → 2名英雄穿戴武器。操作见[建筑](buildings.md)、[装备](equipment.md)及[野外拾取](field.md#拾取野外掉落物)。
3. 通关雾隐迷塔15层 → 英雄升级10次 → 领取最后逐项奖励和章节奖励。操作见[迷塔](tower.md)与[英雄升级](heroes.md#升级指定英雄)。
4. 最终面板显示“第3章 装备锻造”，英雄升级为10/10可领取，建造英雄营地和解锁迷雾小径为1/1绿色勾；该最终可见列表不等于完整章节任务清单。
5. 领取全部奖励后短暂显示“所有任务均已完成”，随后出现新任务；打开清单确认“第4章 迎战女巫”，据此确认第三章结束。第四章只核对标题，未推进。

上述顺序是单次内网开发服体验，具体目标数量、展示顺序及奖励需按当前画面确认。章节标题在任务条末尾出现，不代表此前操作属于章外或此时才刚开始第三章。

## 操作与系统关系

第一章任务推进依次涉及击败魔物、招募英雄、将英雄升到10级，之后继续引导挑战首领并建造木材场、煤炭场、铁矿场及净化中枢。建设引导由建筑等级前置关系串联。第一章任务面板在新手体验中列出三项主要目标；后续建设是教程继续推进内容，不应据此推断任务面板只会永远包含三项。

### 第二章任务和章节奖励需分别核验

- 状态：已验证。
- 结论：第二章《雾隐迷塔》依次展示建造地下城、探索迷塔、通关指定层数、英雄升到1星等目标。通关10层与升星目标完成并领取逐项任务奖励后，面板可领取章节总奖励；领取后主城任务条显示“所有任务均已完成”。
- 界面判断点：通关第10层后，任务面板显示10层(1/1)与升星(0/1)；升星完成后显示升星(1/1)可领取。建造地下城(0/1)和探索雾隐迷塔(0/1)旁曾出现绿色勾；领取任务奖励及章节奖励后主城明确显示“所有任务均已完成”。
- 解释：第二章目标状态、逐项任务奖励和章节总奖励是分开的；任务计数与勾选标记的矛盾属于显示异常，不能仅凭0/1推断任务仍未完成。
- 适用范围：内网开发服新手阶段；第2章“雾隐迷塔”。
- 最后核实日期：2026-10-10。
- 相关问题或条目：第二章个别计数与绿色完成勾曾不一致；遇到此现象应继续核对任务奖励状态与主城完成提示。

### 第二章后续目标在领取任务奖励后逐步出现

- 状态：已验证。
- 结论：第二章《雾隐迷塔》不是一开始就展示全部目标。新手流程先引导建造地下城、探索迷塔、通关第3层；随后出现第5层、史诗招募10次、3名英雄达到10级等目标。领取已完成目标的奖励后，面板继续出现4名英雄达到10级、通关第10层；领取4名英雄10级的奖励后，又出现1名英雄达到1星。应在每次领取后重新查看任务面板。
- 界面判断点：主城左下任务条进入“第2章 雾隐迷塔”面板；任务行的“领取”可用时领取，返回面板查看新增行及其进度；最后领取章节总奖励后，主城任务条显示“所有任务均已完成”。
- 解释：目标完成、逐项奖励领取、新目标展示和章节总奖励领取是不同的推进节点。第3、5、10层是已观察到的层数里程碑；当前面板优先于记忆中的顺序。
- 适用范围：内网开发服新账号第二章《雾隐迷塔》；其他构建的任务顺序需以画面确认。
- 最后核实日期：2026-10-10。

## 各玩法任务核验

以下内容属于主线调用玩法后的核验，独立玩法操作仍以对应文档为准。

- **建筑引导：**教程可通过地图红色建筑标志或任务条打开建造面板。首领战后按木材场→煤炭场→铁矿场→净化中枢串联；第二章建造地下城后解锁迷塔，再返回任务面板领取奖励。地下城任务曾显示0/1但可领取或有绿色勾，须结合建筑完成提示、玩法入口及奖励状态核验，保留为显示异常。
- **招募任务：**第一章要求招募1次；第二章展示史诗招募10次。招募结果出来后返回主线核对对应类型和次数是否计入，再领取奖励；免费单抽与道具十连的操作、成本见[招募](recruitment.md)，不把一次历史消耗固定为任务通用成本。
- **野外任务：**第三章手势用于寻找英雄营地与迷雾小径；解锁区域、派遣4人后等待自动击杀3个怪物达标，无需反复操作怪物。拾取3次、5次目标均通过点击地面掉落物推进；每次领取后核对任务计数，达标再领取任务奖励。一次点击、掉落堆数与道具数的精确计数关系仍未知。
- **装备任务：**第三章先打造练习剑并完成1名英雄穿戴，后打造练习弓并完成2名英雄穿戴。亚诺与幽夜姬装备槽出现武器、战力增加是玩法结果；回主线核对穿戴人数才是任务结果。打造成功不能替代穿戴目标完成。
- **升级次数任务：**第三章通关15层后，亚诺从10级升至20级的十次逐级升级使任务达到10/10；核对任务行并领取奖励。次数目标与英雄最终等级目标分别读取，不能互换。
