实现细节、新字段、政策支持范围和语义检查职责见 [P2 契约](p2-contracts.md)。保留 P1 五工具、SDK 客户端及运行账本恢复协议，没有迁移游戏宿主技能。

- **109 项测试通过**：包含原有 72 项 P0/P1 回归和 37 项 P2 检查。覆盖页面事实替换、旧资源未知、同单位差值、单位改变、历史窗口外失败、成功解除、旧工具拒绝兼容、跨游戏隔离、公告不注入全局目标攻略、必需知识缺失、身份绑定、字符预算边界及实际 SDK 传输字符数、冲突分析/修订、草案证据及便携性、政策变更、并发编辑、两文件部分发布、SQLite 回滚后重试、finish 草案与无完成断言。报告：`run/p2-20261012/pytest.xml`。
- **模拟 stdio 验收通过**：官方 Python MCP Client 启动同服务实现，发现五工具并通过 9 项协议/上下文检查。测试客户端只在 fixture 入口注入，生产入口没有模拟开关。记录：`run/p2-20261012/stdio-mock-acceptance.json`。
- **真实 Jev stdio 验收通过**：最终验收 run `be9e4809803c4b9c9fecbb7391ba9e1f`，固定生产入口 `python -m jev_game_agent`，服务报告 0.3.0。两次请求均返回 `jev-1.13.0`，共 1,880.40 ms，HTTP 尝试 2 次，无重试。公告输入 2,254 字符且无知识；迷塔输入 5,474 字符，检索迷塔路径、入口、结算及相关解锁规则，资源差值为 -100 枚。重复 submission 不再请求，完成证据终止后续判别。记录：`run/p2-20261012/stdio-live-acceptance.json`。
- **桌面 MCP 验收通过**：重启加载的 0.3.0 服务发现 P2 字段并完成模拟 run `f2283d57d8f14fe98235ac08aafe5d0b`。真实 Jev `jev-1.13.0` 两次判别合计 2,890.40 ms，输入分别 2,095 和 5,342 字符。公告页未检索知识；迷塔页检索相关条目，将公告旧事实标成非当前信息，并保留金币 -100 枚的同单位差值。重复 submission 返回保存结果且 `execute_allowed=false`。最终任务凭合成截图证据完成。UI 输入及共享知识写入均为 0。桌面检查通过：五工具及新增 schema 可见、P2 指令描述已加载、控制流与 12,000 字符限制生效。记录：`run/p2-20261012/desktop-host-acceptance.json`。

## 复现

在项目根目录执行：

```powershell
.venv/Scripts/python.exe -m pytest -q --junitxml=run/p2-20261012/pytest.xml
.venv/Scripts/python.exe scripts/verify_p2.py --output run/p2-20261012/stdio-mock-acceptance.json
.venv/Scripts/python.exe scripts/verify_p2.py --live --output run/p2-20261012/stdio-live-acceptance.json
```

最后一条读取现有 TYPESAFE_API_KEY，通过真实服务发送两次小请求；不输出凭据，不执行 UI。终端网络在本宿主需要授权；这不是当前桌面 MCP 请求逐轮免审批的 P2 验收证据。
